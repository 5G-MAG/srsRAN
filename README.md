## Introduction

This repository is forked from
[Austrian-Broadcasting-Services/srsRAN](https://github.com/Austrian-Broadcasting-Services/srsRAN),
and its default branch is `fembms`. The later version of the suite, srsRAN_4G, has its own 5G-MAG
fork: [5G-MAG/srsRAN_4G](https://github.com/5G-MAG/srsRAN_4G).

The srsRAN suite includes:

* srsUE: a full-stack SDR 4G/5G-NSA UE application (5G-SA coming soon)
* srsENB: a full-stack SDR 4G/5G-NSA eNodeB application (5G-SA coming soon)
* srsEPC: a lightweight 4G core network implementation with MME, HSS and S/P-GW

For information, guides and project news, see the [srsRAN project pages](https://www.srsran.com).
For application features, build instructions and user guides, see the
[srsRAN documentation](https://docs.srsran.com).
